# PULSE TWO — минимальная стоимость запуска (обновлено 10 ноября 2026)

Это план именно для текущего Node.js + WebSocket + WebRTC приложения. Код в этом репозитории — MVP; не все нативные функции iOS готовы.

## 1. Самый дешёвый тест: $0

- [Render Free](https://render.com/docs/free) — создать Web Service из этого репозитория через файл `render.yaml`, команды уже указаны: `npm ci` и `npm start`.
- Бесплатный адрес `*.onrender.com` сразу работает по HTTPS. Домены покупать не надо.
- **Ограничения**: засыпает после 15 минут простоя, последующий запуск около минуты. Вся локальная папка `data/` стирается при спящем режиме, рестарте или деплое. «Капсула времени», переписка и чек-листы для постоянной эксплуатации на нём **ненадёжны**.
- В текущем `render.yaml` `autoDeployTrigger: off`: в уже созданном сервисе после обновления кода нужно нажать Manual Deploy, либо в Settings → Auto-Deploy включить After CI Checks Pass.

## 2. Дешёвый постоянный сервер: Railway Hobby, от $5/месяц

[Railway pricing](https://docs.railway.com/pricing/plans) — Hobby стоит $5 минимум, первые $5 использования ресурсов включены, сверх лимита расходы оплачиваются отдельно. На Free есть $1 месячных ресурсов, этого для постоянно работающего сервера может не хватить.

Как запустить:

1. Создать проект в Railway → Deploy from GitHub Repo → `29889dgvwd-ai/pulse-two`.
2. Команда запуска: `npm start` (build: `npm ci`).
3. Создать публичный домен Railway (Generate Domain / Networking). Свой домен покупать не обязательно.
4. Подключить **Volume** к веб-сервису, путь монтирования `/app/data`. Это сохраняет комнаты, сообщения, капсулы и планы после рестарта.
5. В Variables задать `PULSE_DATA_DIR=/app/data` и `NODE_ENV=production`. Порт Railway выдаст автоматически.
6. После Deploy проверить `https://<выданный-домен>/health` — ожидается `{"status":"ok"}`.
7. Открыть сайт на **двух телефонах**, создать комнату, зайти по коду, проверить чат, игры, живые карточки, звонок и восстановление после рестарта.

Рекомендации и ограничения Volumes: [Railway docs](https://docs.railway.com/volumes).

Если сервис работает постоянно, счёт может быть **выше $5**, потому что CPU/RAM/volume/передача данных учитываются вместе. Поставить лимит расходов в Railway и проверить фактическое потребление за месяц. Гарантированную цену без замера нагрузки назвать нельзя.

## 3. Альтернатива: Render Starter

[Render pricing](https://render.com/pricing) и [persistent disks](https://render.com/docs/disks): платный web service от $7/месяц, дополнительный диск оплачивается отдельно. Подключить диск на путь `/opt/render/project/src/data` и выставить `PULSE_DATA_DIR=/opt/render/project/src/data`. Это доступно только на платном инстансе.

## 4. Стоимость и ограничения всех функций

| Функция | Самый дешёвый технический путь | Статус в коде |
| --- | --- | --- |
| Чат, 12 игр, задачи, 10 совместных активностей | Один постоянно работающий Node.js сервер (Render/Railway) | Реализовано, требуется проверка на двух устройствах |
| Хранение сообщений, капсул и планов | Постоянный Volume (Railway Hobby / Render paid disk) | Сохранение в JSON реализовано |
| Голосовой чат | WebRTC+STUN, затем TURN при проблемах NAT | WebRTC реализован; TURN пока не подключён |
| Надёжный TURN | [Cloudflare Realtime TURN](https://developers.cloudflare.com/realtime/turn/faq/): 1000 ГБ бесплатно, далее $0.05/ГБ. Нужна выдача временных учётных данных с backend, ключи нельзя вставлять в public JS | Требуется реализация и проверка |
| Push на экран заблокированного iPhone | Web Push с Service Worker и VAPID, только установленное на экран Домой PWA с согласием пользователя (iOS 16.4+) | Ещё не реализовано |
| Вибрация iPhone по кнопке партнёра | Нативная iOS обёртка c haptics при открытом приложении; вне приложения — уведомление с системной вибрацией, не произвольный паттерн | Есть заготовка Expo; не собрана и не проверена |
| Настоящие iOS виджеты на домашнем экране | WidgetKit / Swift + App Groups, iOS app и подписывание сборки | Не реализовано |
| App Store | Apple Developer Program $99/год, публикация, проверка и юридическое требование возраста совершеннолетия владельца аккаунта | Не реализовано |
| Собственный домен | Необязательно, используйте выдаваемый HTTPS адрес | Не нужен |

Cloudflare TURN: [прайс и включённый трафик](https://developers.cloudflare.com/realtime/turn/faq/).
Web Push на iOS: [Apple Developer](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers).
Developer membership: [Apple](https://developer.apple.com/help/account/membership/program-enrollment/).

## 5. Что проверить перед использованием

- Тесты `npm test` должны проходить; GitHub Actions показывает результат на коммит.
- Проверить оба iPhone в разных сетях: Wi-Fi и LTE, реальный голосовой звонок, возобновление связи, вход и выход.
- Не пересылать в приложение секреты: пока идентификация по коду комнаты, нет полноценной авторизации, сквозного шифрования и резервных копий. Двухфакторный вход и приватность добавить прежде, чем массово публиковать приложение.
- Не хранить ключи TURN, уведомлений или хостинга в GitHub (использовать переменные окружения).
- Для PWA: Safari → Поделиться → На экран «Домой». Это не полноценная нативная .ipa.

**Оптимальный старт:** сначала Render Free для демонстрации. Для реального использования 2–4 людьми — Railway Hobby c Volume и бесплатным поддоменом, с проверкой фактического счёта. Затем добавить TURN и PWA Push. Для системных iPhone виджетов и собственного паттерна вибрации понадобится нативная iOS-часть.
