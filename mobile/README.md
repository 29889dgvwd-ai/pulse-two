# PULSE TWO Mobile (Expo)

Обёртка для iOS/Android поверх опубликованного PULSE TWO. В отличие от браузера Safari, может включать **настоящую тактильную отдачу на iPhone**, когда приложение открыто.

## Запуск
1. Размести основной Node.js-сервер на HTTPS-сайте.
2. Скопируй `.env.example` в `.env` и укажи `EXPO_PUBLIC_APP_URL=https://твой-домен`.
3. В папке `mobile`: `npm install`, затем `npx expo start`.
4. Открой в Expo Go или собери dev/production build через EAS.

Звонки внутри WebView могут требовать дополнительных разрешений и тестирования на реальном устройстве. Для гарантированной работы звонков на iOS/Android лучше вынести WebRTC в нативный модуль.

Вибрация работает только в открытом приложении. **Фоновые push-вибрации** и виджеты на системном домашнем экране потребуют отдельной нативной реализации с push-уведомлениями и WidgetKit/App Widgets.
